# 故障处置手册（六类故障树 + 家属问答）

## 一、车坏

**触发**：爆胎、断链、后拨变形、辐条断、碟片蹭。

| 情形 | 立即动作 | 升级 |
|---|---|---|
| 爆胎 | 靠边、离开车道、换内胎（自备 2 条） | 连续两次爆胎 → 检查胎内异物或换外胎 |
| 断链 | 用快扣接回；无快扣则改单速骑到最近镇 | 到新山车店（Pusing Cycle / Giant JB） |
| 后拨摔歪 | 扳正尾钩，限速骑，禁用大飞轮 | 车店换尾钩 |
| 无法修复 | 叫 Grab（选 6 座，备注带自行车）或拦皮卡 | 跳段到下一住宿点 |

**必带**：内胎 2、补胎片、迷你气筒、CO₂ 气嘴（当地买气瓶）、快扣、多功能工具、刹车片 1 副、辐条 2 根。

## 二、人伤

| 情形 | 立即动作 | 升级 |
|---|---|---|
| 摔车擦伤 | 清创、消毒、贴敷料；检查车架与轮组 | 伤口深或污染 → 就近诊所 |
| 疑似骨折 | 不动伤处，固定，叫救护车（马来西亚 999 / 新加坡 995） | 送公立医院急诊；同时报保险 |
| 中暑先兆（停止出汗、发冷、头晕） | 立即进加油站/AEON 空调区，补电解质，松衣领 | 意识模糊 → 立即急救 |
| 抽筋 | 停骑、拉伸、补盐丸与电解质 | 反复发作当天收工 |

**理赔材料清单**（事后必留）：病历、诊断书、费用发票原件、事故现场照片、同行人书面说明、报警记录（如有）。

## 三、证件丢失

1. 立即到最近警局报案，取**报案纸**（这是补办与理赔的唯一凭证）。
2. 联系中国驻马来西亚使馆（吉隆坡）或驻新加坡使馆，办**旅行证**。
3. 旅行证到手后，向航司申请改签（保留原票号与报案纸）。
4. 护照复印件与电子扫描件存云端 + 每人手机相册各一份，是补办提速关键。

## 四、纸箱丢失或延误

1. 落地未取到 → 当场在 T2 航司行李服务柜台开 **PIR**，拿编号与电话。
2. 留马来西亚本地号码，24 小时内主动追问一次。
3. 若 48 小时未到：评估改买新纸箱（吉隆坡车店可给新车箱），或先骑行、回程再处理。
4. 索赔材料：PIR、行李牌、箱体照片、购买/打包凭证、行程证明。

## 五、关卡被拒

| 原因 | 动作 |
|---|---|
| MDAC 未填或填错 | 退回马来西亚侧，手机重填，确认后再过 |
| 护照问题（页损/有效期） | 换关口无用，联系使馆 |
| 被要求出示离境机票 | 出示 1/3 回程票 |
| 长时间排队 | 05:00–05:30 到；否则改 Larkin 大巴带车过境 |

## 六、天气

- **午后雷暴**：11:30 前完成主里程；听到雷声立即进加油站/店铺避雨，不在树下与广告牌下。
- **持续暴雨**：当天改跳段（大巴/包车），不硬骑。
- **积水路段**：下车推行，先探深度，不冲水。

## 七、行李超规被拒运（青岛机场当场）

1. 要求值机主管到场，出示此前客服答复记录（工号、时间）。
2. 现场改走**航空货运**（同航班或次日航班），人货分开，留收货人信息。
3. 极端情况：改签下一班或改由吉隆坡方向其他航司承运（成本高，作为最后手段）。
4. **不要在现场把车丢弃或寄回**——先解决运输，再谈行程。

## 八、家属问答（给三姑的版本，可直接转发）

**问：会不会被抢？**
答：路线走西海岸城镇与联邦公路，天亮出发、天黑前入住，不走偏僻小路。现金分三份放，不集中在一人身上。马来西亚与新加坡整体治安好于多数东南亚国家。

**问：生病了怎么办？**
答：三人都有旅行医疗险；随身带肠胃药、退烧药、防蚊液、盐丸；重症就近公立医院，同时联系使馆。

**问：车丢了怎么办？**
答：车架号已拍照备案，随车不离人，住宿选能放车进房的；真丢按保险流程走，有报案纸就能理赔。

**问：多久能知道消息？**
答：每天中午 12 点、晚上 8 点各报一次平安，发定位。当晚住哪家酒店会提前发群里。

**问：联系不上怎么办？**
答：超过 6 小时没消息，先打队长电话，再打另两人，再打酒店前台，仍无消息联系使馆领保。

**问：飞机上那些箱子怎么办？**
答：寄存在吉隆坡机场的官方寄存柜台，24 小时有人，凭护照和收据取，1 月 2 日回去取。
