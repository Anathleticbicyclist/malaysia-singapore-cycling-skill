# 打包清单（三人三车 / 9 天 / 热带雨季）

用法：出发前逐项打勾，装箱后拍照留档。责任人填"队/导/装"（队长/导航/装备）。

## 一、证件与钱（随身，不放纸箱）

- [ ] 护照 ×3（有效期 ≥2027-06-25），塑封防水袋
- [ ] 护照复印件 ×3 + 电子扫描件存云端
- [ ] MDAC 确认页截图（含回马那次）
- [ ] SGAC 确认页截图
- [ ] 回程机票行程单（打印 + 手机各一份）
- [ ] 保险单（含 24h 救援热线）
- [ ] 信用卡 ×2（不同行）、银联卡 ×1
- [ ] 现金：RM 800–1200 + SGD 150–200，分三人分处存放
- [ ] 酒店预订单（首晚 + 各日）

## 二、骑行装备（每人）

- [ ] 头盔（新加坡公路强制）
- [ ] 骑行眼镜（透明 + 变色各一）
- [ ] 手套 2 副
- [ ] 骑行服 2 套、袖套、腿套
- [ ] 雨衣（轻薄款，雨季必带）
- [ ] 骑行鞋 + 鞋套
- [ ] 前后灯（可充电，日间闪烁模式）
- [ ] 码表 + 备用充电线
- [ ] 水壶 2 个（750ml）
- [ ] 小背包或尾包（装证件与雨衣）
- [ ] 防晒霜 SPF50、唇膏
- [ ] 盐丸 / 电解质片

## 三、修车工具（三人分摊，不重复带）

- [ ] 内胎 ×4（28–30c，含每车 1 条备用）
- [ ] 补胎片 + 胶水
- [ ] 迷你气筒 ×2
- [ ] CO₂ 气嘴 ×1（**气瓶到新山再买**，不能上飞机）
- [ ] 撬胎棒 ×3
- [ ] 多功能工具 ×2
- [ ] 链条快扣 ×3
- [ ] 截链器 ×1
- [ ] 刹车片 ×2 副
- [ ] 辐条 ×2
- [ ] 电工胶带、扎带、备用螺丝
- [ ] 小瓶链条油（密封袋装）

## 四、纸箱与托运相关

- [ ] 纸箱 ×3（长边 110–115cm，四角护角）
- [ ] 气泡膜 / 泡沫管（护后拨、碟片、前叉）
- [ ] 打包带 ×6、宽胶带 ×2
- [ ] 记号笔（箱面写姓名/航班/电话 "FRAGILE BICYCLE"）
- [ ] 电子秤或家用体重秤（称箱重）
- [ ] 卷尺（量三边和，值机时报数）
- [ ] 束带（箱内固定车架）

## 五、药品（队内共用一包 + 个人自备）

- [ ] 肠胃药、蒙脱石
- [ ] 退烧止痛（**避开含伪麻黄碱的复方感冒药**，马来西亚属受控）
- [ ] 防蚊液（含 DEET）
- [ ] 创可贴、碘伏棉签、弹性绷带
- [ ] 晒伤膏、肌肉酸痛贴
- [ ] 个人长期用药（原包装 + 处方复印件）

## 六、电子与通讯

- [ ] 马来西亚电话卡（或 eSIM，落地 T2 买/激活）
- [ ] 充电宝（随身，不托运）
- [ ] 多口充电器 + 英标（G 型）转换头 ×2
- [ ] 离线地图已下载（马来西亚、新加坡全境）
- [ ] Grab 已装并绑定支付
- [ ] 车灯/码表/电变电池（**电池随身**，不装箱）

## 七、随身小件袋（最易丢，单独一袋）

- [ ] 车钥匙 / 锁
- [ ] 码表（可拆下随身）
- [ ] 水壶架螺丝、尾包扣
- [ ] 备用眼镜
- [ ] 小毛巾

## 八、装箱纪律

1. 装箱**全程拍照**：走线、把立、坐管刻度、后拨位置，回程按图复原。
2. 轮胎**放掉约一半气压**再装箱（高空气压差）。
3. 车架号（Serial Number）拍照，与整车照、发票一起存云端。
4. 碟片、后拨、前叉叉脚加护件，车架用束带固定箱底，不悬空。
5. 装箱后记录：三边和（cm）、重量（kg），写在箱面并拍照。
