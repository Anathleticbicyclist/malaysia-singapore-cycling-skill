# 新马跨境骑行作业规范

处理"中国→吉隆坡→骑行→新加坡→骑回吉隆坡→飞回中国"这类跨境骑行。核心不是路线，而是**纸箱托运—提取—寄存—取回**这条链和**陆路通关**。

## 铁律（违反即视为方案失败）

1. **青岛航空 QW907 / QW929 落地 KLIA Terminal 2（KLIA2）**，不是 T1。所有行李厅、寄存、打车方案按 T2 排。飞常准显示 QW907 到达 T2、行李转盘 8、到达口 P5。
2. 青岛航空国际航线**经济舱免费行李仅 1 件、每件 ≤23kg、三边之和 ≤158cm**（2026-05-08 起计件制）。公路车纸箱 200–230cm **必然超标**，属超规件，必须提前电话确认接收政策，不能到机场再赌。
3. 青岛航空《行李运输限制相关规定》把"**运动用自行车**"明确列入"只能作为托运行李的物品"——允许托运，这是法理依据；但同时写明"超过规定体积限制且旅客拒绝改善者不得作为行李运输"，所以超尺寸必须事先获批。
4. **Woodlands 是唯一能骑自行车过的关口**；Tuas Second Link 不可行（两侧接入高速公路，新加坡 LTA 将 bicycle 列为 expressway excluded vehicle）。不得安排 Tuas。
5. 过 Woodlands 必须走**最左侧 manual motorcycle/bicycle lanes**，下车推行、走人工柜台；自动 e-Gate 不接骑行者，QR 通关也不适用于骑行者。
6. 马来西亚**高速公路禁止自行车**（LN167/59 第 17 条），可罚至 RM5,000 或监禁 12 个月。只走 Federal Route 1、Route 52 等非高速路段。
7. 寄存报价写**按件按 24 小时**，注明是否含超规档；未拿到书面报价的标"待确认"，不得估算成事实。
8. 里程、爬升必须来自 BRouter/OSM 实算或明确标注"估算/待实测"，禁止编造。
9. **中国护照赴马免签依据是 2025-07-17 生效的中马互免协定（5 年、自动续 5 年）**，不是"2026 年底到期"的临时政策；赴新免签依据是 2024-02-09 生效的中新互免协定（≤30 天）。两者都仍需电子入境卡：马来西亚 MDAC、新加坡 SGAC。
10. 护照有效期 ≥6 个月；纸质护照装防水袋。新加坡禁电子烟、口香糖、咀嚼烟草，过关前清包。
11. 默认走西海岸走廊（吉隆坡—芙蓉—马六甲—麻坡—峇株巴辖—笨珍—新山）。12 月至 1 月东北季风期，东海岸洪水风险高，不得排东线。
12. 交付必须含"待办核实清单"，把查不到或只能现场确认的项单列，不给假确定性。
13. 装箱前给两条胎**各放掉约一半气压**；车架号（Serial Number）、整车照、购买发票必须拍照存云端，这是丢失索赔的唯一凭据。
14. 超规件在货舱的**运输优先级低于普货**，载重或天气受限时第一批被卸下——证件、药品、当日必需物一律随身，绝不放进纸箱。
15. 携带现金超 **US$10,000 等值**须向马来西亚海关申报；三人分摊携带，不集中在一人包内。
16. 家属报平安机制必须写进方案：每日 **12:00 与 20:00** 各发一次定位，超 **6 小时**未报即启动"队长→另两人→酒店→使馆"联络链。
17. 排程按**最慢的人**算，不按最快的人；**18:00 强制收工**，剩余里程次日补或跳段。
18. 任何"待确认"必须配落实路径（找谁、拨哪个号、问什么、怎么留证、多久跟进），写进 `references/verification-channels.md`；只写"待确认"而不给路径，视为未完成。
19. 口头答复不算依据：政策与费用类结论必须拿到**工号 + 邮件书面回复**，出发前 7 天再复核一次。
20. 寄存费按**阶梯价**算，不是一口价（自行车：第 1–6 天 RM48、7–14 天 RM42、15 天起 RM40），报价与预算都要按段拆。
21. 自行车属"**拟复带进境的自用物品**"，出境时必须在海关申报台填单、验核、盖章；不申报，回国按**不可分割单件全额征 20%**（自行车在 20% 档），三台可能上万。这条必须在交付里点名。
22. 马来西亚**陆路**入境免税额度只有 **RM500**（空路 RM1,000）；**备胎内胎属"轮胎与内胎"必须申报**，别当普通行李。
23. 保险必须覆盖**境外医疗救援、自行车损坏、第三方责任、行程延误**四件；只写"买份保险"等于没写。

## 六步工作流

### 第 1 步 需求解析（缺项就问，一次最多问 3 个）

必须拿到：航班号与承运航司（去/回）、纸箱线性尺寸与满箱重量、人数与是否都骑、寄存天数与预算、回程是否骑回或坐车。

### 第 2 步 自行车上飞机

读 `references/airline-bike-logistics.md`。要点：
- 先算线性尺寸（长+高+宽），再对照该航司上限，不要凭经验。
- 青岛航空：经济舱 1 件 23kg、三边和 ≤158cm；自行车可托运但超尺寸须事先获批。同航班同行旅客免费行李额可合并计算（计件制下合并件数）。
- 输出：每件行李的计费档位、需电话确认的三个问题、建议到机场时间（三人三箱提前 3 小时）。

### 第 3 步 落地提取与地面运输

读 `references/kila-baggage-storage.md`。要点：
- QW907 落 T2：到达口 P5、行李转盘 8；超规件通常不上普通转盘，直接去超规行李处。
- 未到件当场开 PIR，不要离场再报。
- 三人三箱需 MPV/van 或包车；KLIA Ekspres 不接非折叠车，不要安排坐快线进城。

### 第 4 步 纸箱寄存（本流程唯一硬卡点）

读 `references/kila-baggage-storage.md` 的"方案比选"与询价四项。
- 首选 **KLIA2 的 Baggage Solutions**：Gateway@klia2 公共区 L1-08 / L2-136A，24 小时，**自行车等超规件 RM48/件/24h 起**，可存数周，需护照，支持支付宝/TNG。
- 次选 T1 Smart Storage（Level 3 到达层，按尺寸计费）、机场周边酒店代存、市区仓库、KL Sentral 第三方 left luggage。
- 必须问清：最大可存尺寸、按件还是按体积、第 7 天起是否降价、取件时间窗、超期处置、三人能否合并计价。
- 用 `scripts/storage_cost.py` 算三档预算。

### 第 5 步 陆路通关

读 `references/border-crossing.md` 与 `references/visa-entry.md`。要点：
- 05:00–05:30 上 Woodlands 引桥，避开摩托通勤潮。
- 去程：新加坡侧最左人工通道出境 → 过 1km 长堤（注意轨道缝与金属格栅）→ 上斜坡进 BSI → 最左人工/外国人通道盖实体章。
- 回程：从新山走 motorcycle approach ramps 进 BSI，同样人工柜台。
- 三人各自过闸，约定集合点。

### 第 6 步 路线与 GPX

读 `references/route-corridor.md`，用 cycling-route-planner skill 出 GPX（BRouter 路由），按天拆分，标注里程、爬升、补给、住宿锚点。跨境日单独留 2–3 小时过关缓冲。

## 交付五件套

1. **行程方案**（Markdown）：逐日路线 + 过关时间点 + 住宿锚点 + 备选跳段。
2. **成本与清单**：托运、寄存、包车、住宿四类费用试算；`assets/packing-list.md` 打勾版。
3. **随身流程卡**：A5 可打印，含过关步骤、寄存柜台地址电话、单号栏、应急电话。模板见 `assets/pocket-card.md`。
4. **时间轴与分工表**：T-45 到 T+0 倒排待办，责任到人。模板见 `references/time-axis-checklist.md`。
5. **故障处置与家属问答**：六类故障树 + 可直接转发家属的问答。见 `references/contingency-playbook.md`。

## 脚本

`scripts/storage_cost.py`：寄存费用测算，支持按件按天、阶梯单价、人均分摊。

```text
python scripts/storage_cost.py --items 3 --days 9 --rate 48
python scripts/storage_cost.py --items 3 --days 10 --rate 48 --tier2 42 --tier2-from 7 --people 3
```

## 交付前自检

- [ ] 是否确认落 T2，并按 T2 排行李厅、寄存、打车
- [ ] 是否给了纸箱线性尺寸，并对照青岛航空 158cm 上限判定
- [ ] 是否提醒"超规必须提前电话获批"这一拒运风险
- [ ] 寄存是否拿到"最大尺寸 + 单价 + 时长 + 取件时间窗"四项
- [ ] 过关是否只走 Woodlands，写明人工通道与下车推行
- [ ] MDAC 是否写明"每次入境都要重填"（含新加坡回马那一次）
- [ ] 是否避开高速公路，路线是否来自实算
- [ ] 是否提醒"放气 + 拍车架号 + 证件不进纸箱"三件事
- [ ] 是否提醒**出境海关申报（复带进境登记）**，并说明漏报按 20% 全额征税
- [ ] 是否说明马来西亚陆路额度 RM500、备胎内胎须申报
- [ ] 是否给出保险四覆盖、投保六问与理赔材料
- [ ] 是否给出 T-45 到 T+0 倒排时间轴，且责任到人
- [ ] 是否覆盖六类故障（车/人/证件/箱/关卡/天气）的处置动作
- [ ] 是否产出可直接转发家属的报平安与失联机制
- [ ] 是否按最慢的人排程，并写明 18:00 强制收工
- [ ] 待核实项是否单列，没有伪装成结论
